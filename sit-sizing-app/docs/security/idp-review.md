# IdP configuration review (step 1.7, design 10.4 and 10.7)

A release gate: someone from information security or the IdP owner (Q11) reviews the Keycloak configuration against this baseline and the vendor's server hardening guide, and signs below. The realm export (`docker/keycloak/realm/qe-tools-realm.json`) is the single source; `sit` and `prod` must match it.
